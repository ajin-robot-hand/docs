# 팀 블로그를 시작합니다

이 글은 팀 블로그의 첫 번째 예시 글입니다. 팀원들은 이 형식을 참고해서 각자 진행한 작업을 기록하면 됩니다.

<!-- more -->

## 새 글 작성 방법

1. `docs/blog/posts/` 아래에 `YYYY-MM-DD-제목.md` 형식으로 파일을 만드세요.
2. 파일 상단에 아래와 같은 front matter를 작성하세요.

   ```yaml
   ---
   date: 2026-08-12
   slug: my-post-slug   # 제목이 한글이면 꼭 영문 slug를 지정하세요 (안 그러면 URL이 한글 인코딩으로 지저분해집니다)
   categories:
     - <본인 author id>   # docs/blog/.authors.yml 에 등록된 id
   authors:
     - <본인 author id>
   ---
   ```

3. `categories`에 본인의 author id를 넣으면, 사이트의 "작성자" 카테고리 페이지에서 특정 팀원이 쓴 글만 모아볼 수 있습니다.
4. `<!-- more -->` 위쪽 내용은 목록 페이지에 미리보기로 노출됩니다.
5. 아직 `docs/blog/.authors.yml`에 본인 프로필이 없다면 추가한 뒤 커밋하세요.

## 로컬에서 미리보기

```bash
pip install -r requirements.txt
mkdocs serve
```

`http://127.0.0.1:8000` 에서 결과를 확인할 수 있습니다.
